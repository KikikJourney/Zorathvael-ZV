# Community Code of Conduct

## Our standard
Participation in the Zorathvael repository should be respectful, constructive, evidence-based, and safe for contributors of different backgrounds and experience levels.

## Expected behavior
- Be respectful and assume good faith while discussing technical disagreements.
- Provide reproducible evidence for bug reports and factual claims.
- Critique ideas and code, not people.
- Disclose security concerns responsibly.
- Respect privacy and never publish personal information, credentials, seed phrases, or private keys.

## Unacceptable behavior
Harassment, threats, hate speech, doxxing, spam, impersonation, deceptive promotion, deliberate misinformation, and attempts to solicit wallet secrets are not acceptable.

## Enforcement
Repository maintainers may edit or remove harmful content, close discussions, or restrict participation where permitted by platform rules. Report concerns through GitHub's reporting mechanisms or a private security report as described in [SECURITY.md](SECURITY.md).

This code of conduct does not guarantee that every report can be resolved or that a particular response will be taken.
