# Contributing to Zorathvael (ZV)

Thank you for helping improve the project's public documentation.

## Before opening a change

- Keep claims factual, specific, and supported by public evidence.
- Do not add price predictions, guaranteed returns, fabricated partnerships, fake audits, or unverified liquidity/authority claims.
- Never include seed phrases, private keys, API tokens, personal financial information, or private user data.
- Use the complete mint address when discussing token identity.
- Keep changes focused and explain why they are needed.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Token addresses and external links have been checked.
- [ ] Claims about on-chain state include a source and UTC observation time.
- [ ] No secrets or private data are included.
- [ ] Markdown links and formatting have been checked.
- [ ] Security-sensitive changes have been reviewed carefully.

## Review

Documentation changes may be edited for accuracy, clarity, and safety. Changes involving code, wallet connections, signing, token transfers, smart contracts, or automated trading require a separate technical design, tests, threat model, and independent review before deployment.

## Conduct

Be respectful. Spam, impersonation, harassment, deceptive financial promotion, and attempts to solicit wallet secrets are not acceptable.
