# Zorathvael (ZV) — FAQ

## What is ZV?
Zorathvael (ticker: ZV) is presented in this repository as a meme token on Solana. The repository is a public documentation and maintenance hub; it does not claim that ZV has a separate blockchain or a completed utility ecosystem.

## Is ZV an investment or guaranteed to increase in price?
No. This repository makes no promise of profit, price appreciation, liquidity, listings, or future utility. Meme tokens are speculative and may lose all value.

## Is the on-chain configuration audited?
Do not treat this repository as an audit. Supply, decimals, metadata, and mint/freeze authorities must be read from the live chain and checked independently.

## How can I report an issue?
Use the repository's GitHub Issues and include reproducible evidence. Never post seed phrases, private keys, passwords, or wallet exports.

## How do I avoid impersonators?
Use links published in this repository, verify the full mint address, distrust unsolicited direct messages, and never connect a wallet or sign a transaction just to claim an unsolicited reward.
