# Zorathvael (ZV) — Roadmap

This is a planning document, not a promise of delivery, price performance, token utility, exchange listings, or financial returns. Items remain **planned** until the work is complete, reviewed, and linked to evidence.

- [x] Establish public repository.

- [x] Add risk disclosures and contribution/security guidance.
- [ ] Commit the supplied official logo file.

## Phase 1 — Trust and maintenance
- [ ] Publish a dated on-chain verification report with sources.
- [ ] Verify and link official community channels.

- [ ] Enable repository security and branch protections where available.

## Phase 2 — Community-led improvements
- [ ] Collect community proposals through public issues.
- [ ] Evaluate each proposal for feasibility, security, cost, and maintenance burden.
- [ ] Publish accepted/rejected decisions with concise reasoning.
- [ ] Build only features with a defined purpose, owner, tests, and maintenance plan.

## Out of scope unless explicitly designed and reviewed

This repository does not currently provide a new blockchain, node/client implementation, staking, rewards, bridge, exchange, wallet, smart contract, or token utility system. Such features must not be advertised as live until they exist and pass appropriate independent review.

## Change control

Roadmap changes should be made through commits or pull requests. Do not silently convert plans into claims of completion.
